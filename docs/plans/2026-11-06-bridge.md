## Context

The hook gate passed (2026-11-06, `ed66812`): the interposed `glClear` runs about 29 times a second on
the main thread, the engine's `lua_State*` is set by the first call, and Lua was idle at all 28,800
calls. ADR-0005 is active. Phase 2 turns the probe into the bridge: on the first safe `glClear` it
registers a temporary `A7X_native` table of read-only functions into the game's Lua, using the game's
own Lua API, and otherwise passes every call through.

**Decisions made (2026-11-06):**

- `native/builds.h` is written by hand from the analysis below, documented in `docs/re-notes.md`, and
  checked by a Deno test against the installed game binary. `deno task derive` waits for a second build.
- The native API is ADR-0002's: one `A7X_native` table with `Version`, `Root`, `Read`, `ReadBlock`.
  No Lua mod yet, so the global stays visible in this phase (Phase 4's `a7x_api.lua` captures it).

## Design

### `native/builds.h`

```c
enum a7x_fn { A7X_FN_lua_checkstack, ..., A7X_FN_COUNT };      /* the 11 functions above */
struct a7x_site { const char *name; uint64_t offset; uint8_t len; uint8_t bytes[32]; };
struct a7x_build {
    const char *name; uint8_t uuid[16];
    uint64_t lua_state, baldur_chitin;                          /* globals */
    struct a7x_site fns[A7X_FN_COUNT];                          /* call targets, each byte-checked */
    struct a7x_site anchors[2];                                 /* the code that encodes each global */
};
```

Expected bytes: the first 32 bytes of each function (the whole function when shorter), and 32 bytes at
each anchor. One line per site, in a regular form the Deno test parses. `A7X_LUA_STATE_CI` and
`A7X_LUA_STATE_BASE_CI` stay.

### `native/a7x.c`

- **Constructor:** `LC_UUID` match, then `memcmp` of every site against the mapped image. Logs
  `A7X build 2.7.3 arm64 matched, 13 checks passed` or `A7X disabled: bytes differ at <name> (+0x…)`;
  on failure `build` stays NULL, so nothing is read or called.
- **`a7x_glClear`:** always ends in `glClear(mask)`. Until registered, and only on the main thread:
  read the `lua_State*` global, read `L->ci`, and register when it equals `&L->base_ci`. A failed read
  disables the bridge with one log line (fail closed, fixing the probe's gotcha); busy Lua just waits
  for the next frame. After registering it re-reads the global each frame, and if a different
  `lua_State` appears it logs that and registers again. The probe's count lines go.
- **Registration, protected:** `lua_checkstack(L, 2)`, push the C function `a7x_register` (a light C
  function, no allocation), `lua_pcallk(L, 0, 0, 0, 0, NULL)`. Inside, `lua_createtable`,
  `lua_pushcclosure` + `lua_setfield` per function, `lua_setglobal("A7X_native")`. Any Lua error,
  including a GC finalizer's, comes back as a return code: log the message (`lua_tolstring`), pop it
  (`lua_settop(L, -2)`), disable. Logs `A7X registered A7X_native at <t>s, glClear call <n>`.
- **The four functions** (args via `lua_tointegerx`/`lua_tolstring`, results via
  `lua_pushinteger`/`lua_pushlstring`; returning no values gives the caller `nil`, so no `lua_pushnil`
  and never `lua_error`):
  - `Version()` -> `1, "2.7.3 arm64"` (native API version, build name).
  - `Root()` -> the value of `g_pBaldurChitin`, or nil if unreadable or null.
  - `Read(addr, kind)`, kind `u8 i8 u16 i16 u32 i32 ptr cstr` -> integer, or for `cstr` up to 256
    bytes to the first NUL, read page by page; nil for a bad kind, `addr < 1` or `> 2^53`, or a
    failed read.
  - `ReadBlock(addr, len)`, `1 <= len <= 4096` -> a string of exactly `len` bytes, or nil.
  - All reads go through `mach_vm_read_overwrite` (the existing `read_pointer` generalised to
    `read_bytes`). No write path.

### Deno side

- `src/re/macho.ts`: `archSlice(bytes, "arm64")`, `imageUuid(slice)`, `segment(slice, "__TEXT")`.
- `src/re/builds.ts` (new): `parseBuilds(text)` reads the sites and UUID from `builds.h`;
  `checkSites(slice, build)` returns mismatches.
- `test/re/builds_test.ts`: the parser on `builds.h` itself; a flipped-byte fixture is reported; a
  real-data case (ignored when the game binary is absent): the slice's `LC_UUID` equals the entry's,
  `__TEXT` has `vmaddr 0x100000000` and `fileoff 0` (so offsets equal file offsets), and every site
  matches. `deno.json`'s `test` task gains read access to the game folder, scoped like `doctor`'s.
- `src/lint/security.ts`: `ALLOWED_ENGINE_CALLS` (the 11 names); `native-engine-call` finding for any
  `A7X_FN_` enum member outside it. Probe tests in `test/lint/security_test.ts`.
- `src/game/launch.ts`: `play`'s summary prints every `A7X` line (the open follow-up), with a test.

  `T("block", #N.ReadBlock(N.Root(), 64))`); repeat `T("vtable", …)` after loading a save and after an
  area change; quit. Pass: checks passed, registered line, version `1 2.7.3 arm64`, root non-nil, the
  vtable inside the game image (the constructor line logs the image base), `bad` nil, `block 64`, no
  `LUA ERROR`, normal play.
